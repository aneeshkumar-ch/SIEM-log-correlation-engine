Incident Investigation Scenarios 5 Briefs
1. Brute Force Authentication Critical / High
An external threat actor attempts rapid password guessing against SSH or Windows authentication, followed by potential successful access.
T1110 / T1110.001 Threshold: ≥5 failures in 10m
2. Suspicious Process Execution High
A non-admin user logs on and immediately launches an administrative interpreter (PowerShell / cmd.exe) or living-off-the-land utility within 2 minutes.
T1059.001 Window: 2m Post-Logon
3. Privilege-Related Activity High
Elevation of rights detected: Windows Event 4672 special privileges assigned or unauthorized Linux sudo/su execution by non-admin accounts.
T1548 / T1078 Indicators: Event 4672, sudo / su
4. Network-Based Suspicious Activity High / Med
Reconnaissance or probing detected via perimeter firewall: a single source IP probing ≥5 destination ports/hosts or generating high-volume blocked packet bursts.
T1046 Threshold: ≥5 ports in 5m
5. Sensitive File Access & Lateral Movement High
Credential dumping attempt on Linux system credentials (/etc/shadow) or same user pivoting across multiple endpoints in short succession.
T1003.008 / T1021 Targets: /etc/shadow, multi-host logons
8-Step Investigation Workflow SOC Playbook
Step 1
Read the scenario brief
Review attack vector, expected indicators, and baseline hypothesis.
Step 2
Search in Kibana
Query security-events* in Discover using KQL filters.
Step 3
Filter relevant events
Isolate events by suspicious source IP, impacted host, or specific username.
Step 4
Analyze timeline
Examine event sequence chronologically to track adversary progression.
Step 5
Identify pattern
Pinpoint anomalous frequency, abnormal execution, or privilege shift.
Step 6
Check correlated alert
Correlate with alerts in security-alerts* on the SOC Triage Board.
Step 7
Document evidence
Extract deterministic event IDs and log evidence into the findings record.
Step 8
Reach a conclusion
Classify true/false positive and outline remediation recommendations.
